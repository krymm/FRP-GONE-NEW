## How to Use
1. Put your Samsung device into **EDL Mode** (Qualcomm 9008).
2. Find your exact **model number** (e.g. `SM-A526U`) on the device label or via `adb shell getprop ro.product.model`.
3. Navigate to the matching folder in this repository.
4. Select the appropriate firehose loader from the `firehose/` subfolder (or try `loader_bit/` / `firmware_packages/` if needed).
5. Load the firehose programmer in your EDL client and proceed with flashing or servicing.

This page documents the implementation of the Qualcomm Firehose Protocol within the EDL (Emergency Download Mode) tool.
The Firehose Protocol is a low-level communication protocol used to interact with Qualcomm devices in EDL mode, enabling operations such as flashing, reading, and erasing partitions.
...
The Firehose Protocol serves as the primary communication mechanism after a device has been initialized via the Sahara Protocol.
It provides a structured way to send commands to a device and receive responses, facilitating operations on device storage and memory.
...
|Parameter|Description|Default Value|
...
|MemoryName|Type of storage (eMMC, UFS, NAND)|"eMMC"|
|SECTOR_SIZE_IN_BYTES|Sector size of the storage|512 or 4096|
|MaxPayloadSizeToTargetInBytes|Maximum size of data sent to target|1048576|
|MaxPayloadSizeFromTargetInBytes|Maximum size of data received from target|8192|
|MaxXMLSizeInBytes|Maximum size of XML commands|4096|
...
The Firehose Protocol uses XML-based commands to communicate with the device.
Each command follows a specific flow from creation to execution and response handling.
...
